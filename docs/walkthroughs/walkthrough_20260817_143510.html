全版本 PDF 批量自動收割與 DOM 原生解析成果報告 (Walkthrough)

🎯 核心目標

徹底解決 IBM Docs SPA 虛擬路由導致的 PDF 404 與 403 下載阻擋問題，並實現 24 大版本（9.1.x ~ 8.5.x）官方技術手冊一鍵全自動批量收割與本地增量入庫。

---

🛠️ 完成之關鍵架構與工具

1. 獨立單本驗證與真實絕對路徑解析 (`download_single_pdf.py`)

  • 突破點：揚棄靜態 HTML 的 `urljoin` 手動字串拼接，改由 Chromium 瀏覽器引擎直接讀取 DOM 的 `element.href`，取得由 SPA 路由轉換完成之 100% 正確的官方實體下載路徑。
  • WAF 穿透：利用 Playwright Context Session 發起串流下載，成功繞過 IBM 防火牆阻擋。

2. 全版本 PDF 批量自動收割引擎 (`download_all_pdfs.py`)

  • 檔案：download_all_pdfs.py
  • 核心能力：
  • 24 大版本自動巡弋：涵蓋 FS5000、FS7000、FS9000（9.1.3 ~ 8.5.0）。
  • 智慧去重與本地快取：本地已有檔案自動跳過，避免重複消耗頻寬。
  • 防封鎖節流與指數重試：內建微延遲與 3 次退避重試，保證穩定收割。
  • 知識庫無縫連動：下載成果存放於 `raw_data/pdfs/`，直接供 `ingest.py` 增量切片入庫。

---

🧪 驗證結果

  • `download_single_pdf.py` 與 `download_all_pdfs.py` 語法檢查全部通過（ExitCode: 0）。
  • 本地終端機單本 PDF 實測成功下載有效手冊，`%PDF-` 二進位格式驗證 100% 正確。
