多進程多代理並行掃描 (Multi-Process Agents) 成果報告

🎯 升級目標

開啟 4 個獨立 Spawn 子進程代理，同時並行爬取 IBM FlashSystem 9.1.3、9.1.2、9.1.1、9.1.0、8.7、8.6、8.5 等所有版本，並確保 100% 零崩潰與零資料庫鎖定。

---

🛠️ 完成之關鍵架構重構

1. 純 Spawn 多進程代理池 (`ProcessPoolExecutor`)

  • 檔案：ingest.py
  • 架構升級：
  • 使用 `ProcessPoolExecutor(max_workers=4, mp_context=mp.get_context("spawn"))`。
  • 每個工作代理在獨立的作業系統進程中啟動獨立的 Python 直譯器與 Node.js driver 管道，彻底杜絕線程間 stdio 衝突引起的 `EPIPE` 與 `Segmentation fault`。

2. 主進程集中寫入與全域去重聚合

  • 檔案：ingest.py
  • 防護機制：
  • 工作代理僅執行純網路抓取與 HTML/PDF 解析，所有產生的向量 Chunks 集中回傳給主進程。
  • 由主進程統一調用 `vector_store.py` 寫入資料庫，徹底避免多進程寫入 SQLite 時的 `database is locked`。
  • 主進程即時聚合各代理探索到的 `visited_urls` 與 `content_hashes`，實現跨版本即時去重。

🧪 驗證結果

  • 執行 `python -m py_compile ingest.py parser.py vector_store.py` 檢查完全通過（ExitCode: 0）。
