## 🛠️ 修改檔案與架構實作細節

### 1. 分章節深度鏈式提示詞模組 (`prompts.py`)
- 新增 `build_section_prompt(query_text, context_str, section_name, section_goal, prev_context)`。
- 針對三大章節（一、限制與前置條件；二、詳細實務步驟與 CLI；三、驗證監控與排錯）分別賦予獨立深度的提示詞引導，確保各章節極致詳盡、互不重複。

### 2. 鏈式生成管線與 Markdown 語法自動癒合 (`rag_core.py`)
- **基礎 Token 升級**：將單次 Gemini API 調用配額全面調高至 `maxOutputTokens: 8192`。
- **實作 `_execute_chained_generation`**：自動將長篇架構/操作提問拆解為 3 個獨立章節並行鏈式調用，各章節獨立享有 8,192 Tokens 配額，產出突破 10,000+ 字完整指南。
- **實作 `_heal_markdown_tags`**：自動閉合所有未完結的代碼塊 (````) 與粗體標籤 (`**`)，徹底消除前端解析器吞噬內文的隱患。
- **防禦性全 Parts 聚合**：使用 `"".join(p.get("text", "") for p in parts if "text" in p)` 確保所有代碼與文字區塊完整拼接。

### 3. 前端 GFM Markdown 渲染強化 (`static/index.html`)
- 配置 `marked.setOptions({ gfm: true, breaks: true })`，確保萬字長文與複雜 Mermaid 流程圖、多層 CLI 指令塊毫秒級渲染。
