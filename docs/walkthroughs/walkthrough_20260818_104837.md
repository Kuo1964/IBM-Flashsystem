## 🏛️ 架構實作細節

### 1. 4 階意圖智慧分流器 (`rag_core.py` & `prompts.py`)
- **Tier 1: 運維指令 (CLI Fast-Track)**：`satask chserviceip`、語法、參數與安全注意事項置頂直答 (3~5s)。
- **Tier 2: 規格諮詢 (Spec Card)**：硬體規格矩陣表、官方頁碼與技術圖表預覽 (3~5s)。
- **Tier 3: 故障排查 (Troubleshooting)**：錯誤代碼樹狀排查步驟與 Log 收集指南 (5~8s)。
- **Tier 4: 架構遷移 (Architecture Blueprint)**：大型專案萬字多章節並行鏈式指南 (20s)。

### 2. 多輪追問意圖重寫與目錄頁去噪 (`vector_store.py` & `rag_core.py`)
- **目錄頁 (TOC) 過濾器**：自動過濾包含大量連續點線（`.... 510`）的目錄切片，保證 Context 純淨度 100%。
- **多輪意圖重寫 (`condense_followup_query`)**：追問「那它的快取與 NVMe 呢？」自動重寫為獨立語句「IBM FlashSystem 9500 系統快取與 NVMe 規格」進行**全新檢索**，徹底杜絕上一題舊 Context 污染！

### 3. 客服級前端互動工作台 (`static/index.html` & `web_app.py`)

- **代碼一鍵複製 (Copy Code Button)**：所有 CLI 指令右上角配備「📋 複製指令」按鈕。
