## 🚀 如何使用與日常維護

### 1. 新增 PDF 紅皮書或網站連結
- **上傳 PDF 檔案**：將下載的 IBM FlashSystem 紅皮書 PDF 檔案放入 `raw_data/pdfs/` 目錄中。
- **新增網頁連結**：將 IBM 官方網址寫入 `raw_data/web_urls.txt` 中。
- **執行增量更新**：
  ```bash
  .venv/bin/python ingest.py
  # 或使用 CLI:
  .venv/bin/python cli.py ingest
  ```
  系統會比對 Hash 值，僅處理新新增或修改過的文件與圖片！

### 2. 於 CLI 測試查詢
```bash
.venv/bin/python cli.py query "您的問題或關鍵字" --top_k 5
```
