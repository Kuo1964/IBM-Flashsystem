# 研究與技術方案：網頁版圖片即時渲染與對話一鍵匯出 PDF 解決方案

**研究時間**: 2026-08-20 13:25:00  
**解決問題**:
1. 解決網頁版無法顯示技術圖表 (如 FS5200 Node Canister 後視圖、拓撲架構圖) 的根本原因與修復方案。
2. 實作「提問與回答一鍵匯出為高質感 PDF 技術報告檔」功能。

---

## 🔬 一、問題一：為什麼網頁版無法顯示圖片？（根本原因與修復方案）

### 🚨 根本原因 (Root Cause)：
1. **後端缺少圖片服務路由 (Missing Image Serving Endpoint)**：
   - 提取的 8,000+ 張紅皮書架構圖存放於本地  與專案目錄 。
   - 但  中**完全沒有掛載  或  靜態路由**。
   - 前端點擊「預覽圖表」或 Markdown 試圖載入圖片時，後端直接回傳 。
2. **圖片路徑格式未標準化**：
   - 檢索切片中的圖片路徑有些為絕對路徑 ()，有些為相對路徑 ()，前端無法直接存取本機磁碟路徑。

### 💡 解決方案 (The Fix)：
1. **在  建立通用安全的圖片服務 API**：
   - 新增  路由，安全驗證並自  與專案  返回圖片 。
2. **在  增強圖文關聯**：
   - 當使用者詢問圖表（如「後視圖」、「內部圖」、「機匣圖」）時，檢索器自動關聯圖片切片，並在 Markdown 中以標準語法  輸出，讓網頁對話氣泡**直接內嵌顯示大圖**，並支援點擊放大！

---

## 📄 二、問題二：如何將提問與回答輸出成高質感 PDF 檔？

### 💡 解決方案 (The Fix)：
1. **前端整合專業 PDF 匯出引擎 (HTML5 Print CSS + html2pdf.js)**：
   - 在前端頂部與側邊欄新增 **「📥 匯出 PDF 報告」** 按鈕。
   - 點擊按鈕時，自動將當前會話轉換為具備 **IBM 官方企業藍浮水印、專業排版、表格渲染、代碼區塊與頁碼** 的完整 PDF 技術諮詢報告。
2. **雙軌匯出支援**：
   - **方式 A (標準瀏覽器列印為 PDF)**：觸發專屬列印樣式表 ()，自動隱藏側邊欄與輸入框，直接產出向量級極清晰 PDF。
   - **方式 B (一鍵直接下載 PDF)**：引進輕量開源 ，點擊按鈕 2 秒內自動在瀏覽器背景渲染並下載 。

---

## 🛡️ 三、四階段安全防護實施計畫 (Safe Guardrail Plan)

1. **階段一 (Recon)**：確認  與  影響範圍，保護核心 RAG 檢索管線不受干擾。
2. **階段二 (Spec)**：定義  輸入輸出規範與 PDF 匯出 UI 介面。
3. **階段三 (Code)**：編寫最小變更代碼，補齊 Type Hints 與繁體中文註解。
4. **階段四 (Verify)**：實測圖片路由回傳 200 OK、測試 PDF 產生，並重啟常駐守護進程。
