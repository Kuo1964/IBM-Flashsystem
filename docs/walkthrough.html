IBM FlashSystem 專家系統與 RAG 知識庫建置完成報告

所有組件已全數建置完成，並成功完成資料檢索、動態網頁爬取與多模態模型驗證！

🛠️ 完成項目總覽

  1. Ollama 本地模型配置：
    • ✅ 下載 llama3.2-vision 多模態技術圖表解析模型。
    • ✅ 設定 nomic-embed-text 作為文字向量化模型。
    • ✅ 設定 llama3.2:latest 作為本地生成與解答 LLM。
  2. 核心系統程式碼與演進：
    • config.py: 定義 Ollama API、模型名稱與本機隔離向量庫路徑。
    • parser.py: 支援 Playwright 無頭瀏覽器動態渲染與同網域目錄頁面遞迴爬蟲。
    • vision_processor.py: 自動為 PDF 內之技術圖表生成繁體中文 Vision 摘要。
    • vector_store.py: ChromaDB 50 筆小批次寫入與自動重試機制。
    • ingest.py: 增量更新掃描器 (透過 SHA-256 比對)。
    • mcp_server.py: MCP (Model Context Protocol) 伺服器主程式。
    • cli.py: CLI 維護與檢索測試工具。
  3. 實機測試與數據驗證：
    • ✅ 成功處理 48 本大型 IBM FlashSystem 紅皮書。
    • ✅ 動態爬取 5 大官方技術文檔目錄（涵蓋 49 個延伸版本頁面）。
    • ✅ ChromaDB 向量庫已成功儲存 70,000+ 筆技術段落與圖表摘要！

🚀 如何使用與日常維護

1. 新增 PDF 紅皮書或網站連結

.venv/bin/python ingest.py

2. 於 CLI 測試查詢

.venv/bin/python cli.py query "FlashSystem 9500 拓撲架構" --top_k 5
