# IBM FlashSystem Knowledge Base Context

Fully localized, multi-modal Retrieval-Augmented Generation (RAG) expert system and Model Context Protocol (MCP) Server for IBM FlashSystem storage arrays and SAN Volume Controller (SVC).

## Language

### Storage & Enterprise Architecture

**FlashSystem**:
IBM high-performance enterprise NVMe storage array product line (FS5000, FS5200, FS5600, FS7300, FS9500).
_Avoid_: Storwize, V7000 (legacy naming)

**SAN Volume Controller (SVC)**:
IBM Spectrum Virtualize / Storage Virtualize hardware node pair (e.g., 2145-SV1, 2147-SV3) providing symmetric storage virtualization and volume mobility.
_Avoid_: Storage appliance, virtualization gateway

**Node Canister**:
The hot-swappable hardware controller unit inside a control enclosure containing CPU, cache memory, PCIe adapter slots, and management ports.
_Avoid_: Controller box, node motherboard

**FlashCore Module (FCM)**:
IBM custom NVMe SSD with built-in hardware inline compression and AES-256 encryption without performance degradation.
_Avoid_: Standard SSD, commodity NVMe drive

**Nondisruptive Node Swap (swapnode)**:
The concurrent online procedure to replace active SVC hardware nodes (e.g., 2145-SV1 to 2147-SV3) using a Standby Spare node without application downtime.
_Avoid_: Hard node replacement, offline node swap

**Active Quorum Disk**:
A designated tie-breaker MDisk or drive used to prevent cluster split-brain scenarios during node maintenance or network partitions.
_Avoid_: Heartbeat disk, voting disk

### RAG Engine & Agent Tools

**Model Context Protocol (MCP) Server**:
Standardized RPC server interface (`mcp_server.py`) allowing AI Agents (Antigravity, Claude Desktop) to invoke knowledge base retrieval tools via `@mention`.
_Avoid_: REST API server, custom webhook

**Agentic Storage Gateway**:
The backend reasoning pipeline running ReAct loop, Gemini 3.7 Thinking, and multi-turn tool calling with grounding verification, ensuring web clients receive responses identical to IDE expert sessions.
_Avoid_: Simple single-pass RAG, naive API proxy

**Cloudflare Mobile Portal**:
The responsive, mobile-first and desktop-friendly Web user interface published over Cloudflare Tunnel (HTTPS) allowing field engineers and colleagues to query storage diagnostics seamlessly.
_Avoid_: Localhost-only UI, internal intranet portal

**PIN Access Guard**:
A lightweight shared security token / passcode mechanism protecting external Web API endpoints and preventing unauthorized external access while ensuring safe read-only tool sandbox execution.
_Avoid_: Open public endpoint, complex corporate SSO dependency

**Vision Chart Summary**:
Structured Chinese text summaries generated by Ollama `llama3.2-vision` from extracted PDF architecture and RAID topology diagrams.
_Avoid_: Image OCR, raw image text

**Auto-Provisioning User System**:
A zero-administrative-overhead authentication mechanism where engineers log in using their Employee ID / Name and password on first access, automatically creating isolated user workspaces.
_Avoid_: Manual batch account provisioning, static shared accounts

**Audit Trail Engine**:
A structured SQLite audit logger that records full query text, generated Markdown answers, cited official Redbooks/manual sources (JSON), token usage, estimated costs, and latency per user session.
_Avoid_: Transient ephemeral chat logs, unindexed text logging

**Smart Context Isolation**:
A dual-track multi-turn memory strategy that disambiguates follow-up questions while isolating and wiping prior heavy RAG manual contexts upon topic switching, preventing cross-topic context drift.
_Avoid_: Full-history RAG accumulation, stateless single-turn forgetting
